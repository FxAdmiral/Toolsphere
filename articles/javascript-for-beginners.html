JavaScript for Beginners: Make Your Web Pages Interactive

What is JavaScript?

JavaScript is the programming language of the web browser. HTML gives a page its structure, CSS gives it style, and JavaScript gives it behaviour: reacting to clicks, checking a form, updating text without reloading the page. Every tool on ToolSphere, such as the Password Generator and the Hash Generator, is JavaScript running in your browser.

JavaScript can also run outside the browser, on servers, using Node.js. That is the topic of a later guide.

Running your first JavaScript

The fastest way to try it is the browser console. Press F12, open the Console tab, type the line below and press Enter: 

console.log("Hello, JavaScript!");

To use JavaScript inside a page, put it in a file such as script.js and load it just before the closing </body> tag with <script src="script.js"></script>. Loading it at the end means the page elements exist before your code looks for them.

Variables and data types

A variable is a named box that holds a value.

const name = "Ada";                               // text (a string)
let age = 25;                                       // a number
let isStudent = true;                               // true or false (a boolean)
const skills = ["HTML", "CSS", "JavaScript"];       // a list (an array)
const user = { name: "Ada", age: 25 };              // an object

console.log(name, age, skills[0], user.name);
  • Use const for values that will not be reassigned, and let for values that will change. Prefer const by default.
  • Avoid the older var in new code.
  • The main types are strings (text), numbers, booleans (true or false), arrays (ordered lists) and objects (named properties).

Functions

A function is a reusable set of steps. It can take inputs (parameters) and give back a result (return value). 

function greet(person) {
    return "Hello, " + person + "!";
}

console.log(greet("Ada"));          // Hello, Ada!

const double = (n) => n * 2;        // an arrow function
console.log(double(4));             // 8

Making decisions and repeating work

const score = 72;

if (score >= 70) {
    console.log("Pass");
} else {
    console.log("Try again");
}

for (let i = 1; i <= 3; i++) {
    console.log("Round " + i);
}

const doubled = [1, 2, 3].map((n) => n * 2);
console.log(doubled);               // [2, 4, 6]
  • if and else choose between paths.
  • A for loop repeats code a set number of times.
  • Array methods like map build a new list by applying a function to each item.

Changing the page: the DOM

The browser turns your HTML into a tree of objects called the DOM (Document Object Model). JavaScript can find an element in that tree, listen for something the user does (an event), and change the page in response.

Add this button to your HTML:

<button id="countButton" type="button">Clicked 0 times</button>

<script src="script.js"></script>

And this to script.js:

const button = document.getElementById("countButton");
let count = 0;

if (button) {
    button.addEventListener("click", function () {
        count++;
        button.textContent = "Clicked " + count + " times";
    });
}

The three steps are the pattern behind almost every interactive feature: find the element, listen for an event, then update the page. Notice the if (button) check. ToolSphere uses one shared script on many pages, so each feature first checks that its own elements exist. Without that check, a missing element would cause an error on pages that do not have it.

A safety habit: textContent, not innerHTML

When you show text that a user typed, use textContent. Inserting user text with innerHTML lets the browser treat it as HTML, which can allow an attack called cross-site scripting (XSS). 

output.textContent = userText;     // safe: shown as plain text

// output.innerHTML = userText;    // risky if userText comes from a user

Handling errors

Things go wrong: invalid input, a failed request, a missing element. try and catch let your program respond calmly instead of stopping. 

try {
    const data = JSON.parse('{"ok": true}');
    console.log(data.ok);           // true
} catch (error) {
    console.log("That was not valid JSON.");
}

A real example: choosing random characters

ToolSphere's Password Generator picks characters with crypto.getRandomValues() rather than Math.random(). Math.random() is fine for games and animations but is not designed for security. When a task involves passwords or keys, use the browser's cryptographic functions. Choosing the right tool for the job is part of programming well.

Common beginner mistakes

  • Using = instead of ===. A single = assigns a value. Use === to compare.
  • "Cannot read properties of null". Your code looked for an element that does not exist, usually because of a typo in the id or because the script loaded before the element. Check the spelling and the script position.
  • Ignoring the console. Red error messages tell you the file and line number. Read them first.
  • Copying code without understanding it. Change one thing at a time and see what happens.

Practice project: a word counter

Build a page with a text box and a line that shows the number of words and characters as the user types. You will need:

  • A textarea and a paragraph to show the result.
  • An input event listener on the textarea.
  • The string methods trim() and split(), and length.
  • Handling for an empty box, so it shows zero words instead of one.

Summary

  • JavaScript adds behaviour to web pages.
  • Use const and let for variables, and functions to reuse code.
  • The DOM lets your code find elements, listen for events and change the page.
  • Use textContent for user text and try/catch for risky steps.
  • Read console errors, and change one thing at a time.
