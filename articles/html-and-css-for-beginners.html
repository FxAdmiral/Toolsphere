HTML and CSS for Beginners: Build Your First Web Page

Learn how web pages are built, step by step, and create your first styled page.

What are HTML and CSS?

HTML (HyperText Markup Language) gives a web page its structure and content: headings, paragraphs, links, images and lists. CSS (Cascading Style Sheets) controls how that content looks: colours, fonts, spacing and layout.

Think of a house. HTML is the walls and rooms. CSS is the paint, the furniture and the lighting. Every website you use is built from these two, plus JavaScript, which adds behaviour and is the topic of the next guide.

Your first HTML page

Make a new folder, then create a file called index.html inside it. Paste in this code: 

<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>My First Page</title>
    <link rel="stylesheet" href="style.css">
</head>
<body>

    <header>
        <h1>Hello, world!</h1>
    </header>

    <main>
        <p>This is my first web page. I am learning <strong>HTML</strong>
           and <em>CSS</em>.</p>

        <h2>Things I want to learn</h2>
        <ul>
            <li>HTML</li>
            <li>CSS</li>
            <li>JavaScript</li>
        </ul>

        <p><a href="https://developer.mozilla.org/">Visit MDN Web Docs</a></p>

        <img src="photo.jpg" alt="A short description of the picture">
    </main>

    <footer>
        <p>&copy; 2026 My First Page</p>
    </footer>

</body>
</html>

What each part does:

  • <!DOCTYPE html> tells the browser this is a modern HTML page.
  • The <head> holds information about the page that is not shown on it, such as the title that appears in the browser tab.
  • The <body> holds everything the visitor sees.
  • Most elements have an opening tag and a closing tag, like <p> and </p>.
  • Attributes add detail to a tag, such as href on a link or src and alt on an image.

The picture line points to a file called photo.jpg. Put any image with that name in the folder, or delete that line for now. If the image is missing, the browser shows the alt text instead, which is one reason alt text matters. It also lets people who use screen readers know what the picture shows.

Elements worth learning first

  • h1 to h6: headings. Use one h1 per page, then h2 for sections.
  • p: a paragraph. a: a link. img: an image.
  • ul, ol and li: bulleted and numbered lists.
  • div and span: generic containers with no meaning of their own.
  • button, form, input and label: for interaction.
  • Semantic elements such as header, nav, main, section, article and footer. They describe the purpose of each part of the page, which helps search engines and assistive technology.

Adding CSS

Create a second file next to index.html called style.css. The page already links to it with this line in the <head>: <link rel="stylesheet" href="style.css">. Add these rules to the CSS file: 

body {
    font-family: Arial, Helvetica, sans-serif;
    line-height: 1.6;
    color: #0f172a;
    background: #f8fafc;
    margin: 0;
}

header {
    background: #2563eb;
    color: #ffffff;
    padding: 24px;
    text-align: center;
}

main {
    max-width: 700px;
    margin: 0 auto;
    padding: 24px;
}

a {
    color: #2563eb;
}

.highlight {
    background: #fef3c7;
    padding: 2px 6px;
    border-radius: 4px;
}

A CSS rule has a selector (what to style) and a declaration block in curly braces (how to style it). Each declaration is a property: value; pair.

  • An element selector like body or header targets every element of that type.
  • A class selector like .highlight targets any element with class="highlight". You can reuse a class as often as you like.
  • An id selector like #intro targets the single element with id="intro".

The word cascading describes what happens when two rules disagree. More specific selectors win over less specific ones, and when they are equally specific, the rule that comes later wins.

Try it: wrap a word in your page like this, <span class="highlight">CSS</span>, and see the yellow highlight appear.

The box model

Every element on a page is a rectangular box with four layers, from the inside out: the content, the padding around it, the border, and the margin that separates the box from its neighbours. 

.card {
    box-sizing: border-box;
    width: 300px;
    padding: 20px;
    border: 1px solid #e2e8f0;
    margin: 16px auto;
}

box-sizing: border-box makes the width include the padding and border, which is much easier to reason about. Many developers apply it to every element with * { box-sizing: border-box; }. Open your browser's developer tools with F12, pick the Elements tab, and click an element to see its box drawn on screen.

Layout with Flexbox

Flexbox arranges boxes in a row or column and spaces them out for you. Put three boxes inside a container: 

<div class="cards">
    <div class="card">One</div>
    <div class="card">Two</div>
    <div class="card">Three</div>
</div>

Then style the container:

.cards {
    display: flex;
    gap: 16px;
    flex-wrap: wrap;
}

.cards .card {
    flex: 1 1 200px;
    width: auto;
    margin: 0;
}

The boxes now sit side by side, share the space, and wrap onto new lines when the screen is narrow.

Making your page work on phones

Most visitors use a phone, so your page must work on small screens. Two things help. First, keep the line <meta name="viewport" content="width=device-width, initial-scale=1.0"> in your <head>, or phones will show a tiny zoomed-out version. Second, use a media query to change styles at a chosen width: 

@media (max-width: 600px) {
    header {
        padding: 16px;
    }

    h1 {
        font-size: 1.6rem;
    }
}

To test, press F12 in your browser, then turn on the device toolbar (the phone and tablet icon) and pick a phone size.

Common beginner mistakes

  • Styles do not apply. Check that the CSS file is linked, that the file name matches exactly, and that the class name in the HTML matches the one in the CSS.
  • A missing closing brace. One forgotten } can break everything after it. While building ToolSphere, a single misplaced brace made a whole block of styles apply only on small screens. Your editor's formatting tool helps find these.
  • Wrong file paths. Many web servers treat Photo.JPG and photo.jpg as different files. Use lowercase names without spaces.
  • Missing alt text. Always describe meaningful images.
  • Low contrast. Light grey text on a white background is hard to read. Choose colours with strong contrast.

Practice project: a profile card page

Build a one-page profile that includes:

  • Your name as an h1 and a short bio in a paragraph.
  • A photo with proper alt text.
  • A list of three skills you are learning.
  • Links to two websites you like.
  • A footer with the year.

Then style it with at least one class, one flexbox container and one media query, and check it at phone size. When it works, you have used everything in this guide.

Summary

  • HTML structures the content. CSS styles it.
  • Elements have tags and attributes, and semantic elements describe each part of a page.
  • CSS rules pair a selector with property and value declarations.
  • Every element is a box: content, padding, border and margin.
  • Flexbox lays out boxes, and media queries adapt the page to small screens.
