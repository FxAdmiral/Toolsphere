About Unix timestamps

A Unix timestamp counts the seconds since 1 January 1970 at 00:00 UTC, known as the Unix epoch. Computers use it because it is one simple number that means the same moment everywhere, whatever the time zone. Many databases, logs and APIs store dates this way.

JavaScript and some APIs use milliseconds instead, which gives a number with 13 digits rather than 10. This tool guesses which one you pasted: very large numbers are read as milliseconds.

Timestamps are also handy when reading logs. See our guide Logs, Alerts and SIEM.
