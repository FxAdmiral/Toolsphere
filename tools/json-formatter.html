                            About JSON
                        


                        

                            JSON is a simple text format for data, used by
                            most web APIs. It follows strict rules:
                        


                        
    
                            
  • Keys and text values need double quotes. Single quotes are not allowed.
    • 
                            
  • No trailing comma after the last item.
    • 
                            
  • No comments.
    • 
                            
  • Only true, false and null in lowercase.
    • 
                        


                        

                            Two things to know. If an object repeats a key,
                            only the last value is kept when you format it.
                            And numbers with more than 15 digits can
                            be rounded, so this tool warns you when it sees one.

                            REST APIs guide.
