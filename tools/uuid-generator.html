About UUIDs

A UUID (universally unique identifier) is a 128-bit label written as 32 letters and numbers, for example 3f2504e0-4f89-41d3-9a0c-0305e82c3301. Developers use them as ids for database records, files and requests, because a new one can be made anywhere without checking a central list.

This tool makes version 4 UUIDs, which are random. They are created with your browser's secure random number generator. The chance of two matching is so small it can be ignored.

A UUID is an identifier, not a secret. Do not use one as a password or a security key.
