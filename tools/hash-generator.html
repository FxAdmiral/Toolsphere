About Hashing

Hashing converts data into a fixed-length string of characters. A cryptographic hash is designed to make it difficult to recover the original data from the resulting hash.

SHA-256, SHA-384 and SHA-512 are commonly used modern hashing algorithms. SHA-1 is provided for educational and compatibility purposes and should not be used for new security-sensitive applications.

A plain hash such as SHA-256 is not a safe way to store passwords. Real applications should use a dedicated password-hashing method such as Argon2id, bcrypt or scrypt.
