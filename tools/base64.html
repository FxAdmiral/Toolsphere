About Base64

Base64 turns data into a string made only of letters, numbers, + and /. It is often used to send data through systems that only handle plain text, such as emails and web addresses.

Base64 is encoding, not encryption. Anyone can decode it, so never use it to hide passwords or other secrets.

This tool works with text and handles accented letters, symbols and emoji correctly (UTF-8).
