About JWTs

                        

                            A JSON Web Token (JWT) is a compact string that websites and APIs use to prove who you are.
                            It has three parts separated by dots: a header (which algorithm was used),
                            a payload (the claims, such as the user id and when the token expires) and a
                            signature (which lets the server detect tampering).
                        

                        

                            The first two parts are only Base64URL-encoded, not encrypted, so anyone holding the token can read them.
                            Never put passwords or secrets in a JWT payload.
                        

                        

                            Common claims: iss (issuer), sub (subject), aud (audience),
                            exp (expires), nbf (not before), iat (issued at).
                            Times are shown in UTC.
